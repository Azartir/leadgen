# Lead Engine — версия на русском

Программа собирает организации из открытых источников, проверяет сайты, оценивает
потенциал лида и экспортирует CSV/XLSX. Сбор и проверка не гарантируют, что каждая
карточка актуальна: сверяйте расхождения перед контактом.

## Быстрый запуск

Скачайте `LeadEngine-windows.exe` из раздела [Releases](../../releases) или из
артефактов GitHub Actions. Для локальной разработки нужен Python 3.11+:

```powershell
python -m pip install -r requirements.txt -r gui/requirements.txt
python -m leadgen --list
python -m leadgen --vertical ru_b2b --market stavropol_ru --sources osm 2gis --out stavropol
```

Если ключ 2ГИС задан через переменную окружения, API включается автоматически:

```powershell
$env:DGIS_API_KEY = "ваш-демо-ключ"
python -m leadgen --vertical ru_b2b --market stavropol_ru --sources osm 2gis --out stavropol
```

Получить ключ: [кабинет платформы 2ГИС](https://platform.2gis.ru/ru/playground).
Демо-ключ выдаётся на 30 дней и имеет лимиты запросов; точные лимиты проверяйте
в кабинете и документации [Places API](https://docs.2gis.com/api/search/places/overview).

## Яндекс Карты

Поиск организаций Яндекса требует API-ключа и соответствующей лицензии. Не считайте
этот API постоянно бесплатным. Сначала проверьте [условия лицензии](https://yandex.ru/dev/commercial/doc/ru/concepts/geosearch)
и запросите тестовый доступ у Яндекса.

Для CLI ключ задаётся переменной окружения:

```powershell
$env:YANDEX_MAPS_API_KEY = "ваш-ключ"
$env:YANDEX_MAPS_ALLOW_PROCESSING = "1"
python -m leadgen --vertical ru_b2b --market stavropol_ru --sources osm yandex --out stavropol
```

Переменная `YANDEX_MAPS_ALLOW_PROCESSING=1` — явное подтверждение оператора, что
лицензия разрешает выбранную обработку. Если условия вашего доступа запрещают
сохранение или изменение ответа, не включайте этот источник и не экспортируйте его
данные. Ключи не следует коммитить в Git, записывать в конфиг или отправлять в логи.

В настольном интерфейсе ключи вводятся в поля источников и передаются локальному
процессу только для текущего запуска. Они не сохраняются в localStorage.

## Что означает «проверка»

После объединения источников приложение указывает список источников, совпавших по
компании, и выводит потенциальные расхождения в телефоне, сайте, email или адресе.
Это эвристическая сверка по названию/контактам/координатам, а не подтверждение
юридического статуса. Совпадение названий само по себе недостаточно.

## Сборка EXE через GitHub Actions

Workflow `.github/workflows/build-windows-exe.yml` запускается при push в `main`
и ветки `feature/**`, на pull request и вручную. Он устанавливает зависимости,
запускает тесты, собирает автономный `LeadEngine-windows.exe`, проверяет запуск
локального интерфейса и публикует артефакт на 14 дней.

Чтобы получить EXE:
1. Откройте вкладку **Actions** в репозитории.
2. Выберите **Сборка Windows EXE**.
3. Откройте завершённый запуск и скачайте артефакт **LeadEngine-windows**.

Для выпуска постоянного файла в GitHub Releases создайте и отправьте тег вида
`v1.1.0`. EXE собирается на Windows runner; локальная сборка описана в
[`gui/BUILD_EXE.md`](gui/BUILD_EXE.md).

## Источники

- **OpenStreetMap** — без API-ключа; соблюдайте ODbL и требования атрибуции.
- **Overture Maps** — без API-ключа; данные распространяются по CC-BY 4.0.
- **2ГИС Places API** — демо-ключ или подписка.
- **Яндекс Карты** — ключ и разрешающая обработку лицензия.
- Остальные адаптеры проекта: Socrata, NPI, ArcGIS, Foursquare, Wikidata, CKAN и
  собственные CSV/XLSX.

Не собирайте лишние персональные данные, соблюдайте правила обработки контактов,
условия источников и применимое законодательство о рекламе и персональных данных.
